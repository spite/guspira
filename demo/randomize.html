Randomize & keyboard

Clicking a control's label rerolls that control. A randomize button rerolls the whole panel, or just what follows it if you ask for that. Both go through a random source you can replace with a seeded one, which makes a reroll reproducible.

Try: press R to reroll the panel, S to toggle the seeded source. The second button only touches the controls below it, and Seeded is marked randomizable: false so no reroll flips it. With the seed on, the same seed always produces the same roll — press R a few times, set the seed back, and the sequence repeats. Key bindings ignore presses while you are typing in a field: click into Name and press R. Shift+D is bound once and unbinds itself — press it twice. Hold ] to nudge Spin: that binding asks for repeat, where the others fire once however long the key is held. Detail has its own randomize: drag it anywhere across 0–64, but every reroll — label, Alt+R, or the button — lands between 8 and 16.
