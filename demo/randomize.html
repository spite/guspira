Randomize & keyboard

Clicking a control's label rerolls that control. A randomize button rerolls the whole panel, or just what follows it if you ask for that. Both go through a random source you can replace with a seeded one, which makes a reroll reproducible.

Current roll

Log

Try: press R to reroll the panel, S to toggle the seeded source. The second button only touches the controls below it, and the Source rows are marked randomizable: false so no reroll moves them. With the seed on, the same seed always produces the same roll — press R a few times, set the seed back, and the sequence repeats. Key bindings ignore presses while you are typing in a field: click into Name and press R.
